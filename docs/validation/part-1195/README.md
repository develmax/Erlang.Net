# Part 1195 — restore recorded header paths

The Common Test, Debugger, SSL and SSH profiles now record header paths verified against the pinned Windows OTP 29.1.1 release. The analysis compared decoded abstract code with file paths reduced to basenames. It grouped modules whose forms and debug options already agreed apart from those paths.

The full run generated 1,363 of 1,366 release images. Results were 357 Equal, 1,006 Different and 3 SourceRejected. All previously exact images stayed exact, including ELDAPv3. The generated bytes changed in 69 images. The Dbgi chunk now matches in 51 of them and no new Dbgi differences appeared. OTP prepared all differing images for loading. Three focused tests passed.
