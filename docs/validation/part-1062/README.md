# Part 1062 emit tuples of nonallocating BIFs without a frame

The emitter handles unguarded tuple returns containing literals, input parameters, and calls to erlang:get/1, erlang:self/0, or erlang:node/0. It reserves heap space up front and writes each BIF result directly to the lowest available X register. Input registers remain reserved until their final use. The general path covers other shapes.

All five probe functions execute in OTP without a Y frame. Four instruction listings match after source path normalization. OTP reuses repeated get/1 results, while the new emitter retains both reads.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 2 images common to both differing sets.
