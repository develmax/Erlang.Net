# Part911 Static wx string constructors and guarded forwarding

The static wx queue emitter recognizes a chardata argument converted by unicode:characters_to_binary/1. It creates the zero-slot frame before conversion, keeps the resulting binary in the argument register and emits the queue, receive and environment failure paths from that frame.

A tagged record guard followed by unchanged local argument forwarding now emits a frame-free tail call. The two targeted Windows OTP release images wxToolTip and wxPalette matched completely. wxPalette also uses the shared generated wx build profile.

The wxTextDataObject constructor remains different. It normalizes options through lists:map/2 and a closure. The same remaining pattern appears in wxFindReplaceData and several grid cell editors.

All three focused compiler checks passed, including the deterministic static constructor probe and both release images. [Focused report](focused.json).
