# Part 1072 extract list heads and tails before allocating

For simple unguarded cons clauses with a direct empty-list return, the compiler extracts the list members in X registers and allocates a frame only for named bindings and body temporaries. Repeated variables and complex patterns retain the existing lowering. Non-lists reach function_clause with their original arguments.

The OTP probe checks recursive consumption, both kinds of empty return, a wildcard tail and the original failure arguments. The emitted get_list now precedes allocate. OTP allocates before get_list in the recursive probe and uses get_hd for the wildcard-tail probe.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 199 images common to both differing sets. The Code length gap narrowed in all 199.
