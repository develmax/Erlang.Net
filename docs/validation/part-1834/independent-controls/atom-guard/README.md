The pinned `beam_core_to_ssa:select_val` lowers the guard separately inside each value clause. The select keeps ascending atom keys. The switch traverses its successors in key order and `beam_ssa:linearize_only` materializes independent blocks in reverse postorder. The C# emitter reuses its current atom-key ordering and argument move plan for distinct atom clauses with a shared unary `is_pid` input and independent direct local tails. Unknown keys and rejected guards target the existing function-info label. Closed overlapping keys, coincident tails, different guards, constructed arguments, and dynamic or external targets continue through their existing emitters. This change needs no external .NET package, production BEAM dependency, or copied source. The pinned compiler is the development oracle.
