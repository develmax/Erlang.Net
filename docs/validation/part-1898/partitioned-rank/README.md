# Ranked Windows OTP 29.1.1 compiler differences

All 954 differing files from the fresh Part 1898 corpus were disassembled using the existing `rank-opcode-differences.eval` and the immutable reference cache. Twenty-eight isolated, serial ERTS runs handled at most 35 images and 10 MiB of generated BEAM data per group. The merge checked exact inventory and disjoint per-module function lists. All 954 disassemblies were readable. The batches took 399.06 seconds. Part 1897's single-process diagnostic failed with an ERTS heap allocation error after 524.65 seconds, so there is no completed single-process time for a speedup ratio.
