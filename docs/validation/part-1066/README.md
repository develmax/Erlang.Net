# Part 1066 dispatch on tuple arity before allocation

When all clauses match tuples of different sizes in the first argument, the general emitter groups clauses by arity and dispatches with select_tuple_arity. Each group retains its original clause order. It allocates a frame after selection, then uses the existing pattern and guard emitters. Invalid types and sizes reach function_clause directly. Rejected matches inside a group restore the original arguments first.

The OTP execution probe covers an interleaved arity group, a failed guard with a later matching clause, bad shapes, and the original function_clause arguments. Both OTP and the generated code select arity before allocating. Per-group frame sizes and member extraction still differ.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 155 images common to both differing sets. The absolute Code length gap narrowed in 11 and widened in 144. Branches currently duplicate the maximum-size frame prologue, so the earlier arity selection can increase the Code size.
