Thread-bound code-modification authority applies to the synchronous owning-thread stack. Task.Wait or GetResult can inline a queued child task on that stack; such execution remains synchronous reentrancy. The HOST establishes cross-thread isolation, not a general Task identity boundary. No ExecutionContext/AsyncLocal authority flows to other threads or asynchronous continuations. The publication changelog narrows the earlier source-proposal wording accordingly; no runtime change is required for that documented stack-ownership contract.
