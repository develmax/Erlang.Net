R1 is resolved concretely: token-bearing Anonymous(module:null) performs a Registry-gated, publication-only Volatile reference comparison immediately before interpreted body admission. It does not infer CURRENT/image/handler status or acquire a source lease. Direct interpreted calls with no token retain their existing route. The owning restored loop alone catches its exact token's Retry, releases gates and charges ReduceAsync. This closes the branch that bypasses ordinary source-image admission.

Previous B1/B2 remain resolved. A stable per-key cell is never replaced; every mutation publishes a fresh immutable payload as its last write under Functions.gate. Registry admission validates that payload at its decision linearization point, without entering Functions.gate. Publication after that point affects later invocations. The existing Functions-to-Registry safe external lookup order remains the only nesting direction. Both NamedFunctionReferences and Execution.Expr.Fun pass invocation.OriginalFunction, rather than the temporary factory-created fun, into source admission and undefined_lambda/badfun. Restore does not invoke factories, handlers or bodies.

The source implementation must retain all three admission results, with Retry/Missing owning no lease. Pending-purge waits reclassify after owner control pumping; valid old code precedes no-CURRENT fallback, and CURRENT includes zero-export modules. Badarity remains FunctionTerm.Invoke's first check. Callback lookup/capture is direct undefined_lambda/3 under Registry.gate and invocation is outside gates; missing callback is undef without recursively invoking undefined_function. Do not catch a body's own undef as dispatch failure. Legacy arbitrary public Register factories receive only the documented preflight guarantee; their internals cannot be claimed compiler-admission-safe.
