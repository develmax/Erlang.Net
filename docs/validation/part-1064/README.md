# Part 1064 test shared tuple shapes before frame allocation

The general multi-clause emitter checks a tuple arity before frame allocation when every clause requires it. When the clauses also share a leading atom, the emitter combines the shape and tag checks. Different tags remain clause-local. A non-tuple fallback keeps the original dispatch path.

The probes verify aliased tuples, different tags, a non-tuple fallback and the original function_clause arguments. The shared checks now precede allocate. Remaining differences include per-clause field extraction and branch dispatch.
