# Part 1069 forward tuple fields to tail calls without a frame

Simple tuple arity branches now use the existing X-register argument mover to pass literals and bound values directly to local and external tail calls. The emitter skips unused fields and tests literal patterns before overwriting any incoming argument registers.

The probe exercises local and external calls, repeated operands and the original arguments on function_clause. Both branches now run without a frame. OTP still uses a lower scratch register and can extract directly into the final argument register.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 20 images common to both differing sets. The Code length gap narrowed in all 20.
