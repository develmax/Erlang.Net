# Part 1089 — reuse the Y slot of a last-use call argument

When the first call result remains live after a second call, the general emitter can swap X0 with the Y slot of the second call's first argument. The argument must expire at that call and appear only once in its argument list. The emitter then binds the first result to that Y slot and passes the old argument in X0. The entry call plan now applies to eligible unconditional lifted clauses without self allocation or a guard failure target.

The OTP 29.1.1 probe checks ordinary slot reuse, reuse in a closure, a still-live argument and a repeated argument. The lifted function matches OTP's instruction sequence after normalizing source paths and entry label numbers. The named reuse function has the same frame size as OTP and still orders its Y slots differently.
