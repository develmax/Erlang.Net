The production draft admits the single positive-shape record guard in the structural list planner. It emits the record check against the X register holding the extracted head before the branch owns a frame. The existing continuation emitter computes frame width, call live roots and fallback ownership from the body. The guard's only false branch uses the existing rejection label. For an exclusively nil fallback, the cons-head rejection targets function info while non-cons inputs still test the nil arm. Checked body failure, disjunctive guards, and exact structural controls retain their earlier entry routes. This draft deliberately leaves broader nested record patterns, slot assignment and checked body projection fact propagation to their own proofs. Some functions from the census may use earlier independent emitters. The 12 placement differences are a measured scope, not a number of predicted byte matches.

A standalone fixture contains two positives and two negatives. The positives require the tag before either branch's own first call frame, with one unframed nil fallback and one independently framed fallthrough. The negatives preserve a body `badrecord` after an earlier call and the alternative `skip` of an `orelse` guard. Both the pinned image and accepted Part 1967 image pass eight native cases including the exact first stack location at a bad head and the thrown first call location. The Part 1967 disassembly fails both new positional requirements. Updated C# production and test patches strictly replayed in an isolated tree. The draft has no SDK build or corpus result.
