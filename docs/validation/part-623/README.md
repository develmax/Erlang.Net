# Part623 complete LDAP BEAM emission

The C# compiler now emits a complete ELDAPv3.beam from the Erlang source generated by the C# ASN.1 tool. The three remaining functions, replace_tags/3, to_tlv/2 and from_tlv/2, use a general BEAM emitter for nested patterns, calls, guards, cases, list comprehensions and direct traversal for a fold with an inline function. It plans frame slots and labels before emission. The permanent regression check runs from the pinned ASN.1 schema and checks that the module contains the 130 source functions, two comprehension helpers and both module_info exports.

The original OTP VM loaded the complete generated file. Eleven codec examples matched the installed release for BER bytes and decoded values, and a separate nested tag check also matched. Nineteen successful and failing calls matched an OTP compilation of the same generated Erlang source after normalizing error stacks to their reasons. This is a scoped behavioral comparison.

The C# image is 29,732 bytes with SHA-256 0226349AAEF3248423F20BE197E893BA9FA561BBBD449359AA178854F119E5BD. The installed release image is 99,008 bytes with SHA-256 F137904A4B15CE2FC382264B168B606AB9728B7A5A7C8D641C6937D87CB2ED9D. The release uses the source produced by the original OTP ASN.1 generator. An OTP build of the same C#-generated Erlang also differs from the C# BEAM due to instruction selection, optimization and metadata. Exact release parity remains open.
