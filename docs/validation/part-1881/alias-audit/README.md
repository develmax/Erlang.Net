# Part1881 relaxed tuple alias helper audit

The comparison uses the frozen Part1881 generated binaries and the exact Part1880 retake parent. Five of the 25 modules use retained parent binaries and 20 use the new parent complement. All 75 installed, parent and generated BEAM hashes are recorded in `receipt-inputs.json`, and their file equality was independently checked against the stored module status. The declared mapped-include Yecc cohort has no intersection with these 25 paths.

All 25 modules remain Different. Of those, 22 changed from the parent and three have unchanged generated bytes. Normalization strips function metadata, numbers local labels relative to the function, and masks the make_fun unique value. It retains registers, operand types, literals, call identity, instruction order and all instructions. Raw disassembly equality is distinct from comparing Code bytes.

Of the 28 predicted reference alias-helper keys, 24 now occur across 21 modules. All 24 bodies have an opcode discrepancy. Two additional reference keys appeared in `asn1ct_check:collect_components/1` and `qlc_pt:record_attributes/1`. The one new extra key is `ssh_connection_handler:'-conn_info_chans/1-lc$^0/1-0-'/2`, whose reference arity is 1. The source binds `Fs = record_info(fields, channel)`. The candidate helper captures `Fs`. The reference has substituted the constant. The three other missing keys correspond to discarded-output alias generators in `gen_tcp_socket:terminate/2`, `gen_udp_socket:terminate/2` and `cover:delete_all_counters/0`. Their modules remained unchanged.

Of the 24 matched predicted helpers, 23 have a reference first list split writing the recursive tail straight to x0 while the candidate split writes it elsewhere. Ten have their first opcode divergence at a reference call and candidate move. Six allocate before a reference nonempty-list test. In `asn1ct_check:remove_duplicate_objects/2` the candidate also spills the tuple field that OTP gets after recursion from the retained whole tuple. Each is a measured diagnostic pattern among new helpers. The audit neither changes source nor asserts behavioral or byte parity for them.

The exact successful native comparison used one scheduler and took 51.90 seconds. The first harness attempt passed a CRLF path field to the file API and failed before it could compare the first triple. The retake trimmed the field and kept the original stderr. The hashes, timings and disassembler identity are recorded in `receipt.json`.
