# Part632 specialized LDAP codecs and general protected expressions

The C# ASN.1 writer now generates specialized codecs for all named types in ELDAPv3, including OPTIONAL fields, DEFAULT FALSE, enumerations, choices and inline nested collections. Public encode/decode dispatch to these codecs through the OTP-style arity-one wrappers. The former schema/to_tlv/from_tlv descriptor interpreter is removed. Composite aliases delegate to their underlying codecs. This is not an identical reproduction of every OTP helper body.

Helper placement follows the type tree: encoder wrappers and nested encoder helpers precede decoder wrappers and nested decoder helpers. Disassembly of the complete C#-generated image and the installed release confirms identical relative order for all 254 shared functions. The release has 274 functions and 7,028 disassembled instructions; our image has 262 functions and 23,395 instructions. Nine original BER helpers and eleven compiler-generated comprehension helpers remain absent as distinct functions; eight alternative primitive helpers remain. See [the actual disassembly comparison](disassembly.txt).

The BEAM emitter supports general try/catch expressions without of/after clauses, including nested calls, catch guards, materialized stacks and propagation of unmatched exception classes. The former specialized protected-call lowering remains in use for its existing profile. Unsupported-function diagnostics now identify module, function and arity.

Validation on the admitted OTP 29.1.1 VM matched 51 direct optional/default codec calls and 17 round trips, then 269 additional direct calls and 66 round trips. Cases include nested LDAP messages/filters, inline collections, result enums, missing optional values, explicit defaults, custom outer tags, unknown choice alternatives and invalid booleans/enumerations. Error comparisons cover class/reason; they do not claim identical full stacks. Four nested try/catch outcomes match a separately OTP-compiled probe. The permanent managed-runtime regression checks success/error/exit/throw and stack availability. Generation and BEAM compilation use C#; original OTP is only the oracle.
