# Part 1060 keep a computed call argument in an X register

The general emitter evaluates a single computed argument once, moves its result to the destination X register, and loads the remaining literal and already-bound arguments. Multiple computed arguments still use the original evaluation path.

Both single-computation probes avoid their argument spill to Y registers and produce the same results as OTP. The two-computation probe preserves dictionary side effects in source order. The single-computation probes still allocate two slots because the emitter also saves the incoming parameter and the result used to construct the return tuple. OTP uses a zero-slot frame.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. The generated bytes changed in 968 images common to the differing sets of both runs. The Code chunk length moved closer to the reference in all 968 of those images. This measures size only.
