# Part 1704

Share identical terminal instruction sequences within a function. The pass keeps the last copy, as in OTP 29.1.1 beam_jump share_1, and accounts for deleted line instructions. In functions with exception handlers it restricts sharing to the existing short return shapes outside an active handler. An initial variant merged explicit error exits in six wx images that previously matched. The final implementation preserves exit calls, whose frame state and scope can differ before OTP lowers them. The pass reuses the existing compact writer and label remapping. No dependency was added.

All 1,366 Windows OTP 29.1.1 sources were accepted and compiled. 398 files matched byte for byte, including ELDAPv3 generated from ASN.1 in C#. All 968 differing files passed the OTP loader. The pass changed 281 files and added 19 normalized function matches with none lost. The Code-size gap shrank in 120 images, grew in 159 and stayed the same in two. The overall gap shrank by 434 bytes.
