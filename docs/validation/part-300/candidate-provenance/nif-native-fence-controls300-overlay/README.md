Managed no-argument checks load a separate managed Runtime assembly into a collectible, non-default AssemblyLoadContext and require the specific provider refusal from RequireDefaultProvider, Enter and VerifyPlatform. No native file open or callback is attempted in that context. This checks only the native provider boundary, not managed language custom-ALC support.

Native controls run inside the existing ownership checks, before the existing NativePass message. Owner A is actually initialized and published through its registry reservation using the unchanged trusted native fixture. A controller task holds A's private owner monitor as an explicit scheduling barrier. An owned retirement thread calls the actual image binding retirement path. B's separate-runtime coordinator first reserves its exact image and signals that reservation; it cannot begin initialization until the controller explicitly releases the start event.

The controller performs bounded cancellable entries to the real lifecycle semaphore while A's monitor remains held. Once one probe times out, only the owned A retirement thread can hold that semaphore in this serial check. This is the proof that A reached the global-before-owner exclusion point; ThreadState is not used for that proof. Only afterward does the controller release B's initializer start event. B signals actual entry into its coordinator initializer, reaches the real native initializer and blocks while A owns the lifecycle fence. A blocked owned thread, absent B taint, unchanged native unload counter and the still-held A owner monitor are checked together. This is an artificial managed scheduling barrier around actual native owner/coordinator paths, not a claim that the C unload callback itself contains a barrier.

B's linked initializer cancellation is then requested. The controller releases A's owner monitor so the real native unload/close and B's failed-initializer cleanup can unwind. Both owned threads are joined before their event handles are disposed. Thread and controller failures are retained in an aggregate; the exact previously observed initializer failure may be rethrown by reservation disposal and only that same object is ignored. Runtime cleanup is attempted independently and preserves additional failures. All new waits/probes/joins are bounded to five seconds, below the existing outer tool watchdog.

After joining, the control requires one actual A unload, B cancellation, no B taint and an empty B image binding table. A fresh coordinator reservation on B then loads the same trusted native fixture successfully and retires it, requiring the native unload counter to increase exactly once more. This proves the observed fence was released and did not strand a failed initializer's permission or lease. The control intentionally uses the same physical trusted fixture across the two runtimes. Conservative exclusion of aliases/copies follows from the single default-provider process gate's design, not a separately executed alias/copy matrix.
