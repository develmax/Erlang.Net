# Part 1076 share cons extraction without an empty clause

The general emitter uses an existing entry cons test to share the head and tail reads even when there is no empty-list return clause. A field ignored by all relevant patterns uses no extraction or frame slot. The original arguments remain available on pattern and guard failure.

The OTP probe checks head-only, tail-only and no-field matches, with and without an empty clause, plus guard fallback and original failure arguments. The pinned OTP release was the reference.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 170 images common to both differing sets. The Code length gap narrowed in 49 and widened in 86. The other 35 changed files retain the same Code length gap. A shared read still needs copies to the frame when matching continues there.
