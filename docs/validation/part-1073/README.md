# Part 1073 read only the list fields used by the body

For simple cons entry branches, the compiler uses existing binding analysis to retain only values the body reads. It emits get_hd or get_tl for one needed field, get_list for both, and skips extraction when neither is needed. A single field reuses the tested input register. Repeated variable patterns remain on the generic path.

The OTP probe verifies both fields, a wildcard tail, a named but unused head, and a branch that needs neither field. The generated code still allocates a zero-slot frame in the no-field probe, where OTP returns without a frame.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 6 images common to both differing sets.
