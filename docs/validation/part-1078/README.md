# Part 1078 keep intermediate list tails in X0

For flat multi-cell function head patterns, the general emitter uses X0 to walk the list between checks. The final named tail still binds to a Y slot. Original input arguments remain in Y for failure handling. Nested patterns retain the previous path because they can require scratch registers themselves.

The OTP probe checks an improper list, exact list lengths, alternative clauses and restoration of original function_clause arguments. The pinned OTP release was the reference.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 287 images common to both differing sets. The Code length gap narrowed in 269 files and was unchanged in the other 18 changed files.
