# Part 1059 omit unused entry arguments from the stack frame

The general emitter reuses lexical capture analysis to identify which parameters a single unguarded clause reads. It omits unused parameters from the frame when no function_clause epilogue can need them. Repeated parameters, guarded heads and recursive closures retain the existing argument preservation path. The change is a prerequisite for reserving Y registers only for values live across calls, as in the pinned OTP compiler.

The execution probe covers discarded arguments, an already-bound match, a closure capture and argument recovery on function_clause. The first probe function now allocates two stack slots instead of four. OTP still keeps that function's temporary values in X registers.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. The generated bytes changed in 231 images common to the differing sets of both runs.
