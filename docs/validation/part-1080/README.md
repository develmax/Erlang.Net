# Part 1080 initialize safe entry bindings directly

In a single unconditional clause, the general emitter can write leading literal and nonallocating BIF bindings directly to Y registers before clearing remaining slots. The prefix ends at the first expression that can require a fully initialized frame. Already-bound matches retain the previous path.

The OTP probe checks self and process dictionary lookup on both a present and a missing key, followed by a call and a tuple result. The pinned OTP release was the reference.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 252 images common to both differing sets. The Code length gap narrowed in all 252. In the probe init_yregs clears one slot instead of four. The generated frame still has six slots, while OTP uses three.
