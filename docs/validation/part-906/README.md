# Part906 Inets HTTP URI release metadata

The http_uri build profile preserves the recorded include paths, warning order and app_vsn insertion from the Windows OTP 29.1.1 release. The targeted complete image matched byte for byte and was added to the release regression.

Five wx candidates were rebuilt and compared separately. The initial Code difference in wxGraphicsObject is shared by several generated object methods. OTP uses a tagged tuple check, preserves the object across the class check, performs get(wx_env) as a BIF and trims the stack before queueing the command. The corresponding C# image currently uses a general frame and separate tuple checks. The previous full report contained 251 wx images with differences.

All three focused compiler tests passed. [Focused report](focused.json).
