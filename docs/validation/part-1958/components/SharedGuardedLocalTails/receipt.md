# Share unchanged guarded local tail calls

This is an isolated proposal against corrected Part 1956 source 81fe483cddbe51403b1520e49ebef73f9f394e78c534699dc2f9a7c3b4fa5cdc. The baseline compiler SHA256 is 194e9de374fbebd7d9507b09c11cb2c7a864446315cfd334a63376fae4a9bb23. The reference is Windows OTP 29.1.1 commit ad05823719d77c8faee87348ea39513d4e2f99c5. The source replay validates the entire 907-file parent compiler closure and 908 files after the patch. This proposal is independent of the 1967 Boolean-return patch.

Pinned beam_ssa_share rewrites equivalent control-flow successors to share their operations. The new final-label pass recognizes one exact equality test, its direct local tail, one exclusively referenced alternate label, read-only guard tests and an identical local tail. It inverts the exact test and places a single tail after the alternate guards. Every argument already occupies the same X register on each edge. The caller/callee identity, tail arity, all guard failure labels and source lines survive. Calls with effects, moves, differing targets, framed tails, other entrants or non-guard operations fail this proof. No module name, public API name, literal key or callee is hardcoded. The implementation reuses the existing label reader and reference ledger.

The scouting simulation considered 118 historically ranked modules. It predicted complete connect/4 alignment in three transport modules and a partial TFTP result. The actual one-worker comparison compiled 13 frozen 1956 baseline and overlay images. Both scopes contain nine byte-exact images. It preserves erl_bifs, diameter_gen_relay, local_udp, snmp_verbosity, otp_internal, ECPrivateKey, EnrollmentMessageSyntax-2009, PKIX1Implicit-2009 and PKIX-X400Address-2009. A normalized comparison of 1,611 common functions shows four body changes, three new exact matches and no losses or key changes. The three gains are connect/4 in local_tcp, inet_tcp and inet6_tcp. Tftp_engine:print_debug_info/4 remains different. No entire image changes exact status, and all 13 candidate images pass pinned native loader preparation.

The permanent fixture fails on frozen 1956 and passes with the candidate. Its positive function has the same normalized shared tail as the pinned fixture, and the baseline has duplicate tails. Native ERTS matches twelve cases covering accepted and rejected guards, original function_clause arguments, changed argument values, distinct targets and ordered effects. Both C# builds and SDK layout checks pass. After final LF normalization, a fresh build succeeds, the fixture and native replay still pass, and the independently emitted local_tcp image retains SHA256 4006e07bea5a97f24b4c4b75f31c5e86682546c923e72d0c22070f664fc9a2be.

Both production and fixture patches apply with whitespace errors enabled. Strict replay reproduces the four sealed files and keeps earlier fixture registrations.
