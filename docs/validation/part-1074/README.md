# Part 1074 match tuple list heads before allocation

The entry list emitter checks the tuple type, arity, tag and literal fields in X registers. It extracts only the bindings that the body reads and leaves the incoming argument registers untouched before a possible failure. Repeated variables and deeper nested patterns retain the existing path.

The probe verifies tagged and untagged heads, omitted fields, an improper list, the empty branch, and original function_clause arguments after failed shape or literal tests. The original OTP release was the reference.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 115 images common to both differing sets. The Code length gap narrowed in all 115. In the probe the generated frames still have one extra Y slot, and the untagged branch uses get_list where OTP uses get_hd.
