# Part 1077 avoid extracting wildcard list fields

The general pattern emitter skips wildcard list fields and uses get_hd or get_tl when it needs only one member of a cons cell. It retains the nonempty tests and any final empty-tail test. This applies to nested and multi-cell patterns emitted through the general path.

The OTP probe checks selective reads, an improper list accepted by an open pattern, exact length checks, alternative clauses and original function_clause arguments. The pinned OTP release was the reference.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 525 images common to both differing sets. The Code length gap narrowed in all 525.
