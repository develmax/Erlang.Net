# Part 1067 test and extract tuple fields before allocation

Single-clause arity groups with simple unguarded patterns now test literals and extract fields in X registers before allocating a frame. They copy the bound fields and parameters into the frame. Failed tests branch directly to function_clause with the original input registers. Multi-clause groups and complex patterns retain the existing path.

The probe covers a mixed group with a guard, two single-clause groups, two input arguments, and failure on a literal field. OTP still chooses smaller frames and sometimes retains the entire tuple across a call.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 104 images common to both differing sets. The Code length gap narrowed in 72 and widened in 24 compared with part 1066. Relative to part 1065, before arity grouping, the gap remains wider in 142 files.
