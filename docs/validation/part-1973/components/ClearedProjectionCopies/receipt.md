# Cleared call projection copy pairs

This source-only retake implements the scoped removal from the pre-call projection copy-cycle audit. The 857-image overlay found 36 unprotected instruction sites in 35 functions and 24 modules with the measured bounded shape, an existing clear and no corresponding cycle in pinned OTP. One of these sites is mnesia_backup:read/1. This count describes frozen disassembly. It is not a generated candidate result.

The late compiler pipeline calls a shared decoded-code rewrite immediately before final physical label ordering. The rewrite removes only the save and same-register reload around up to five nonallocating moves or projections. The original X has no intervening write. Any read or write of the ephemeral Y in that interval blocks the edit. The second bounded window admits current argument moves, line annotations and frame initialization. The existing InitYRegisters must clear that Y before the ordinary call and any other operand use blocks the edit. Function debug/protected paths and the disabled optimizer paths retain their original code. No stack widths, instructions with effects, line table entries or GC root scheduling are changed.

The permanent regression covers direct X0 and X1 projections with exact expected frame initializers. Negatives include no clear, clearing only another Y, live Y before either boundary, old X overwritten, a heap check, and an interval longer than five instructions. The test also keeps an independent Y redefinition after the call. Its checked-path comparison is coded against the private decoded instruction rewrite used by the normal pipeline.
