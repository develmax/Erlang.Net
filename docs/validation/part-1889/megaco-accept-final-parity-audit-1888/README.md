## Bounded first proposal

The broad opcode evidence consists of 80 candidate windows in 40 modules with 44 unique same-signature pinned anchors across 36 modules. All measured candidate modules are Different. This is an upper bound from the physical test shape. The source gate is narrower. It accepts only a genuinely returned case with an exact static external selector, a guard-free atom arm returning that same atom, and a separate guard-free tagged arity-2 tuple arm with an unread payload and no ambient binding of that name. It routes tag and arity mismatch directly to the original CaseEnd while preserving the entire tuple body and its incoming scope. The atom arm keeps the selector in X0. Explicit returning-result provenance is propagated to nested case results. Fixed arity and failure checks remain. The rule is SSA-gated. The no-SSA pinned control also partitions by type, but uses test_arity/tag projection instead of the typed combined tagged-tuple test. That lowering is independent.

Actual do_accept macro-expanded body and the source fixture decline ReadEntryRegisterCase. The generic emitter compiles these from ordinary X0 case clauses. Source around the inner case has only discarded diagnostic literals before the identity or cleanup. The fallback reasons and source annotation remain under the original emitter. File-close, unhandled reply and residual record cases are separate controls. Current known raw witnesses for file-containing functions include compile:write_binary/3, systools_lib:file_term2binary/2 and escript:create/2. Their aliases or used error payloads can decline this first scope. Permanent fixture asserts the rule for both source orders, guarded overlap, nonterminal use, and no SSA. Frozen C, pinned normal and no-SSA, and a candidate-only model agree on 24 exact results, case-clause reasons, and cleanup effects. The raw model's old-block order is preserved. It only attests dispatch equivalence and loader acceptance, not final C# model equivalence.

The proposal is staged in scratch. git apply --check and three syntax checks passed. C# compiler build, permanent test and whole-module retake are still integration tasks.
