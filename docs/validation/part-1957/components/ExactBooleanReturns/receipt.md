# Return exact predicate values

Pinned OTP 29.1.1 commit ad05823719d77c8faee87348ea39513d4e2f99c5 eliminates redundant Boolean-return branching in beam_ssa_opt:redundant_br/2. This implementation applies the same proof to lowered exact equality and nil tests. The success path must directly return true and the target must directly return false. The emitted test computes a total two-argument exact equality BIF and returns its value. Nil tests supply the empty list as the second operand. The fold preserves original operand representations, including type information. A rejected block can be removed only when every explicit incoming reference was folded, the preceding physical block returns, and the label is absent from local, export and closure entry tables. Debug and executable-line streams skip this fold.

The Part 1954 emitted-code census measured 58 differing functions in 34 modules with this return shape. A separate instruction-level simulation predicted exact normalized functions in 35 cases across 25 modules. Scanning all 504 previously raw-exact Part 1954 images found zero matching emitted shapes. These counts are a deliberately bounded attribution heuristic. The implementation can see CFG shapes that later passes may restructure.

The preliminary compiler uses the 903-source Part 1954 plus Part 1955 linked overlay with the 1966 first-local-call correction. The final compiler uses the bound Part 1955 retake source closure. The only intervening inherited source difference was BeamModuleCompiler.AtomOwnedTupleEntries.cs, taken by exact hash from the frozen retake archive.

The final frozen-parent compiler builds from 903 validated inputs and adds one file. The 15-image scoped retake has six raw-exact controls, zero compiler errors and zero raw losses. The normalized replay uses eight earlier corrected Part 1955 pilot images and seven frozen Part 1954 images as the before references. It records 2,106 common functions, 24 changed, 10 gains and zero losses. Native loader preparation succeeds for all 15. The two errors from the preliminary unsealed trial were caused by an invalid reference-ledger lookup in the first binary. The final proof includes both previously failing modules.
