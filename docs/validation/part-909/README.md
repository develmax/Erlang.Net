# Part909 Multi-object wx command wrappers

The emitter validates aliased object records and tuple shapes before allocation. Guards can test tuple fields and plain arguments. It saves arguments in reverse order, emits class checks in source order and restores the arguments for queue_cmd. Tail queue calls deallocate the full frame. Commands that continue to rec or return ok trim the frame first.

The pinned wxGridCellRenderer disassembly establishes these layouts for draw/8 and getBestSize/6.
