# Part 1071 return from the empty-list clause without allocating

The general emitter recognizes functions whose nonfinal clauses require a nonempty list in the same argument and whose final clause returns a literal or an input for the empty list. It tests the list in X registers before allocating, then keeps the empty branch and non-list failure out of the frame. The cons branch uses existing pattern and guard logic.

The OTP probe exercises a recursive cons clause, both forms of empty return, and original function_clause arguments. The generated asn1_db:path_find/3 now starts with is_nonempty_list and returns directly from its empty clause.

The reference opcode analysis found 7772 functions in 707 files with the list-test versus allocate mismatch. At function entry, OTP emits get_list next in 646 files and allocate next in 402. Counts overlap across files. These are opcode cohorts, not counts of matching source shapes.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 398 images common to both differing sets. The Code length gap narrowed in all 398.
