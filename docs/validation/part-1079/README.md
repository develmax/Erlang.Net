# Part 1079 compare literal list fields in X1

For flat function-head list patterns, the general emitter extracts literal heads into X1 and tests them there. Intermediate tails can stay in X0. Named bindings and complex patterns retain the existing path.

The OTP probe checks two successive literal comparisons, alternative-clause selection on either failure, original arguments, exact length checks and improper tails. The pinned OTP release was the reference.

The full corpus has 348 Equal, 1015 Different, 3 SourceRejected. ELDAPv3 is Equal. Generated bytes changed in 267 images common to both differing sets. The Code length gap narrowed in 188 files and was unchanged in the other 79 changed files. The probe frame shrank from six slots to four, while OTP uses two and tests the literals before allocating.
