# Part627 LDAP BER primitive and choice error parity

The generated LDAP codec returns the OTP ASN.1 reasons for invalid integer and Boolean encoding and malformed Boolean and NULL decoding. Choice encoding uses the tuple discriminator and reads the payload only for known alternatives, matching OTP for unknown alternatives and malformed inputs. Extensible decoding can still return an unknown alternative as raw BER.

The original OTP VM loaded the complete C# image and matched the release across twelve checks comparing values, encoded bytes and normalized error reasons. The release BEAM remains byte-different because the generator and compiler emit different function bodies, instructions and metadata.

All three focused tests passed. The 1,366-image corpus recorded 18 exact matches, nine differing images, 488 source rejections and 851 unsupported modules. [Per-image report](otp-corpus.json).
