# Independent bounded test plan — not executed

Use actual adopted connections and bytes decoded independently from controller output. Keep existing packet/byte/segment budgets; every test has an explicit barrier and bounded deadline, no arbitrary sleep or queue enlargement. Preserve raw failure state and original packet/control provenance.

1. **Room but reserved:** hold the head producer before encoding with an explicit barrier while queue capacity is free. Generate a real incoming missing-target LINK reply and monitor noproc reply. They must retain their obligation and eventually publish, without synchronous QueueFull. This distinguishes all-writer admission from old TryRunUnreserved.
2. **Termination under full queue:** fill exactly the real bounded queue, establish remote link+monitor, then terminate their local target. Assert public PID removal/slot FREE follows the chosen documented boundary, while a separate owned exit continuation remains and Done is not orphaned. Drain the actual controller and require each exact EXIT/DOWN control once; termination/quiescence eventually completes.
3. **No early unowned death:** at every phase barrier inspect public liveness, slot ownership, exit registry, Done and callback Unwound as separate facts. If PID is absent while work remains, its exit continuation must still be owned. After drain/retirement all ownership counts reach zero. Do not assert native IsAlive must remain true until remote output completion.
4. **Actor-finally hook failure:** inject an actual bounded writer failure through the connection operation boundary, not a mirrored helper assertion. Done, executingProcesses and callback Unwound must not be abandoned. Verify explicit teardown/failure outcome and absence of a lost live-generation control; do not merely catch an exception and pass.
5. **Many obligations, one owner:** target has multiple remote links and monitors on the same connection. Fill capacity, terminate, then drain one packet at a time. Assert no DuplicateOwner reservation exception, no duplicate terminal control, correct active/pending-link reason and captured monitored target form.
6. **Cancellation roles:** cancel an ordinary blocked send before admission and ensure its reservation releases followers with no packet. Separately cancel/kill a process with owed terminal output; actor Stop must not cancel its owned terminal continuation. Controller/connection retirement may resolve it and must leave no leaked ownership.
7. **Generation replacement:** while terminal encoding/admission is held, retire connection and create replacement. Release old work; no stale packet or link/monitor mutation reaches replacement. Rejected old generation settles once with the original lease released.
8. **Controller death/shutdown:** kill the output controller while ordinary+terminal writers wait. All waiters receive real retirement, shutdown finishes boundedly and Done/exit/output registries drain. No producer waits for a notification from a controller already dead.
9. **Two channels:** block one connection and run independent local actor plus another connection's traffic. Verify progress without a global runtime/mailbox gate held across capacity wait. This detects synchronization errors without inferring deadlock from an observation timeout alone.
10. **State/publication ordering:** block outgoing MONITOR19 and UNLINK35 at admission. Interleave local death, DEMONITOR20 and incoming ACK36, then drain. Assert exact monitor/link identity transitions and emitted frames against the original contract; no rollback of already published work or unsent monitor retained as active.
11. **Slot reuse:** after public FREE and before old terminal continuation ends, spawn a replacement using real capacity accounting. Old cleanup cannot remove/complete/cancel the new actor or reclaim its slot; each slot release happens exactly once. Bind identities by context+PID/epoch, not reused numeric slot.
12. **Trace retry:** a traced linked EXIT waits across repeated capacity notifications. Compare emitted legacy/payload control and raw token to a single-send reference; serialization/serial advancement occurs once, not once per retry.
13. **Oversized frame:** packet larger than byte/segment maximum fails through the explicit too-large policy rather than awaiting impossible capacity forever. Native terminal TOO_LRG closes the connection in pinned source; retain independent original behavior before generalizing exact SDK limits.
14. **Boundary completion:** notification subscription, exact get_data drain and closure wake blocked writers. At end, all admitted packets appear exactly once and all declined/cancelled packets zero times. Test actual payload/control identities, not just task completion or bytes counters.

The old isolated5 full-run cause remains unknown. These tests are proposed evidence to expose concrete source risks; no passing run or deadlock reproduction is claimed by this audit.
