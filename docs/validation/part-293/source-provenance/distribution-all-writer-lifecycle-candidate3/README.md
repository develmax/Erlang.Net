## Implemented source boundary

* Every existing finalized message/control producer is routed to one connection-generation sequencer. Immediate host callers acquire an actual head reservation before serialization and report a typed `InvalidOperationException` subclass when an earlier operation or capacity would block. They do not pretend to suspend a host caller. Live asynchronous overloads wait outside runtime and sequencer gates, serialize only when head, preserve one immutable encoded packet across pressure retries, and link cancellation only to their own live producer.
* Synchronous and asynchronous monitor/unlink publication installs/removes state at the same runtime-gate commit as actual output admission. Failed admission does not leave an installed unsent origin monitor or an unpublished unlink transition. Unlink identities are revalidated before commit. Legacy negotiated monitor behavior is retained: without the complete ProcessMonitor plus NamedProcessMonitor mask, begin/end still install/remove local monitor metadata but emit no MONITOR/DEMONITOR packet; both synchronous and asynchronous paths use that same mask. Immediate host calls preserve the existing synchronous signatures; the additional async calls have not been routed through currently unsupported remote Erlang BIF paths.
* Termination captures and removes remote link/monitor obligations before legacy cleanup, removes public process identity and releases its public slot, and retains a separate runtime-owned exit cursor. The cursor's lifetime does not depend on the cancelled actor token or public `IsAlive`. `Done` waits for actual terminal admission or retirement of each captured generation; actor `Unwound` is protected in `finally`. Cleanup stages collect failures independently, so a throwing cancellation callback does not skip names, aliases, monitors, ports or local linked-exit delivery. `Done`/the exit cursor reports the actual failure after cleanup.
* A terminal cursor advances one obligation at a time without an encoded side backlog. Failure of one channel does not skip other channel obligations. Unexpected publication failure retires the exact captured connection and is retained as a cleanup failure; it is not converted to success.
* Missing-target LINK, UNLINK_ID_ACK and MONITOR_EXIT replies are transferred into a runtime-owned per-connection system task chain before accepted input returns. The input-handler/controller never awaits output capacity from `dist_ctrl_put_data`. Logical tickets and leases are reserved at transfer time, preserving ordering before any later live producer can reserve. Only the head descriptor encodes; later descriptors are unencoded logical signal work; this candidate does not claim a finite native mailbox/signal workload or alter the hard encoded queue budgets.
* All tickets enter the runtime ownership set under the same runtime gate as reservation. Ticket completion covers the complete system descriptor lifetime, including work not started yet or waiting for its predecessor. Quiescence therefore cannot miss pre-start work. Completed system failures are recorded separately instead of disappearing when tasks leave the ownership set. Disposal and halt drain output and exit continuations; halting closes queues before waiting. Retirement invalidates the captured public connection/role before callbacks, attempts every cleanup stage, clears pending/controller bookkeeping in finally, and guarantees controller-kill enqueue on unexpected required-output failure.

Synchronous transfer scopes wrap raw put_data, pass-through input, direct connected process signals and runtime signal admission. Logical output is transferred under the runtime gate, then publication starts outside gates before the public operation returns. An empty head with capacity encodes and commits inline, preserving immediate no-pressure replies. A pressured head suspends only its owned continuation. Synchronous scopes use thread-local storage rather than flowing into unrelated asynchronous work; nested scopes combine their ordered starts. If a HOST caller itself holds an outer runtime gate, publication runs on a worker and that foreign Monitor is never released. No existing immediate output assertions were weakened.

## Pinned OTP source boundary

There is no wait for outgoing reply capacity on the submitting controller. `pinned-link-immediate-extract.txt` shows `dist.c:2268-2271`: the missing-target LINK reply calls dsig_send_exit and asserts SEND_OK before net_message returns; this justifies the no-pressure fast path. `../distribution-all-writer-lifecycle-audit2` contains the separate native busy/suspend and exit-FREE/continuation bindings. Native `ignore_busy` is not equivalent to increasing the SDK's packet/byte/segment budgets. This candidate changes none of those budgets and makes no original runtime parity claim.
