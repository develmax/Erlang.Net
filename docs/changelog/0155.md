**Part status:** implemented and verified on the Windows OTP release corpus.

### Changes

- The fixture checks two predicates before the one guarded frame. The OTP VM verifies both branches with small and large integers and compares the arguments of function_clause.

Its absolute Code size gap grew by 8162 bytes. The single-frame change reduces that gap and preserves allocation counts relative to OTP. No status changes.

## Part 1748 — 2026-11-15 — Trim unused live X registers at stack allocations

**Part status:** implemented and verified on the Windows OTP release corpus.

### Changes

- Reduce the live X count on allocate and allocate_heap using the existing control-flow analysis. Remove only a suffix of registers that have no explicit or implicit read on any supported continuation.
- The fixture asserts a zero live-X count after a get/1 result predicate. The OTP VM checks both return values, process dictionary state and the case_clause error.

### Decisions and compatibility

- Pinned reference is OTP-29.1.1 beam_ssa_pre_codegen:place_frames. Reuse the current frame-placement analysis and operand rewriting. No dependency was added.
