## Part598 — 2026-11-05 — Execute NIFs under a measured FreeBSD .NET host

**Part status:** completed for the finite FreeBSD 15 amd64 community CLR profile; full NIF/platform parity remains open.
**Objective and scope:** run real NIFs under .NET on FreeBSD before starting the 32-bit ABI work, preserve concurrent edits and retain all failures.

### Changes

- Compile portable managed assemblies with pinned SDK 10.0.400 and execute them in FreeBSD 15 amd64 using a SHA256-pinned MIT-licensed community SDK archive 10.0.113 / CLR 10.0.13. Rebuild all used native boundaries on FreeBSD; add the FreeBSD MSBuild native-filesystem condition. No change to global.json or production ERTS dependency.
- Fix the CLR's FreeBSD14 OpenSSL SONAME probe on FreeBSD 15 by resolving the actual library, verifying its OpenSSL 3 identity and setting the supported DOTNET_OPENSSL_VERSION_OVERRIDE. Observed libssl.so.35 / OpenSSL 3.5.6; no crypto or hash checks are disabled.
- Fix FreeBSD RTLD_DEFAULT lookup from CLR JIT code. The optimized C wrapper tail-jumped into dlsym; FreeBSD could not identify a calling ELF object. Retain a volatile result so the return address stays inside the native bridge. The original binary ends in jmp; the fixed binary returns after the call. Preserve provider/layout/one-VM guards and add a managed-origin symbol-scope regression.
- Synchronize VM reports back even on failed test execution; require its saved exit code separately. Record actual CLR, OS and pointer width.

### Decisions and compatibility

Inspect pinned OTP29.1.1 Unix ddll/header sources, FreeBSD 15 rtld caller-scope behavior and official .NET OpenSSL loader source. Reuse NativeLibrary, existing C#/C bridge and the installed CLR; preserve MIT/OTP notices. [Reuse decisions](../dependency-decisions.md). This proves one community CLR/OS/CPU profile, not Microsoft FreeBSD support or other BSD/ARM64 execution. Registered MFA delta is zero.

### Validation and handoff

Initial successful source 6cd54297/run 41949862037 passes six managed/native checks, real C NIF/BEAM execution, same-host original OTP ETF comparison and unchanged original ELF replay. Runs 41948603475 and 41949150295 retain the SSL and JIT-origin symbol failures.
