# Dedicated halt subprocess candidate (2026-10-14)

This isolated candidate extends the validated logical VM foundation with an optional halt/0,1,2 registration and an executable physical endpoint. Default CoreModules still registers 484 MFAs; none of these three optional bindings is promoted into the default erlang registry. No existing source case, outcome, policy, decoder, exclusion, or ordinary oracle protocol changes. Baseline is part241: 4831 SDK source cases, 4825 comparable cases, 151 diagnoses and six exclusions.

Source-only scope before execution: 24 declared subprocess contracts, 22 comparable numeric/error/adapter contracts and two explicitly partial physical contracts (abort and CLR dump). The SDK host executes each in a fresh interpreted and compiled child, 48 children total. The native runner executes each source in one fresh source-compiled OTP VM, 24 children total. These are separate from ordinary ETF outcomes. The two physical differences are explicit contract flags, not new exclusions. All expected statuses and stream bytes are declared before execution; no observed results are copied into expectations.

The parser follows pinned OTP-29.1.1 erlang.erl halt/0 (3357), halt/1 (3383), error_with_info/2 (13494); bif.c halt_2 (4309-4410); big.c term_to_Uint_mask (3545-3567); utils.c erts_unicode_list_to_buf (2862-2942). Options are parsed completely before status, last duplicate wins, uint32 flush_timeout excludes infinity. Positive integer status uses its low 31 bits. halt/1 replaces error metadata with module=erl_erts_errors; halt/2 adds cause=badopt only for option errors. Unicode slogan accepts 1023 scalar characters, rejects an immediate improper tail, and accepts a longer cons suffix without validating it after truncation. Embedded NUL truncates only physical output.

Successful optional calls elect a real owned runtime halt and throw the existing nonreturn transfer. Numeric endpoint returns the actual selected status from the dedicated executable Main. The reusable runtime never exits the OS. Existing admission closure, cancellation ownership, port drain/deadline and quiescence remain real. Subprocess assertions cover catch/after immunity, generated comprehensions, module calls, gen_server and supervisor initialization, stdout/stderr preservation and raw POSIX/Windows exit width. A returned entry is classified by its actual process exit reason; it is never represented as successful halt or an ETF done value.

Abort calls the platform CRT/libc abort in the owned child. Windows disables only CRT report-fault handling to prevent WER UI; expected raw exit is 3, POSIX is 134. CRT stderr/report handling differs from native BEAM and is retained raw rather than normalized. Crash dump writes a real Windows MDMP through a dedicated DbgHelp writer thread or a Linux ELF dump through the bundled createdump child, then exits 1. Linux authorizes only that owned child's PID with PR_SET_PTRACER and resets permission; it does not change sysctl/security policy. No fake dump or BEAM physical format is claimed. Actual CLR logical stack is recorded separately. Dump availability, OS permissions and Linux execution are unverified until the actual subprocess gate runs.

Each child retains its source bytes/hash, separate stage evidence, raw exit code and raw stdout/stderr. A host timeout kills only the owned tree and records infrastructure failure, never a fabricated halt timeout 255. Native compilation errors remain a compile stage failure. Raw abort/dump output is retained with the explicit physical gap; 22 comparable cases have exact predeclared finite streams. Failed checks keep their directories. No public package publication or default API completion is claimed.
