## Implemented behavior

Native declarations now parse field :: specifications with or without defaults, including parenthesized -record(#r{...}). Types support named builtin arities, variables/annotations, literal atoms/integers, ranges/unions/arithmetic, tuple/list/nonempty list/map fields, remote type calls, functions, binary size/unit syntax and record field type syntax. NativeRecordFieldType retains immutable Term syntax and field source offsets; NativeRecordDefinition snapshots the collection. Builtin arities are source-derived from erl_internal:is_type/2. Types describe values; construction/update/defaults never enforce a runtime type. records:get_definition/2 intentionally continues returning only original export/default data. Code generation emits type metadata only for typed declarations, preserving existing untyped output.

Defaults follow erl_eval:partial_eval and erl_lint:check_field_default_1. Eager unary/binary operators recursively evaluate only the original operand forms and must produce an integer, float or atom to replace the operator node. Container literals recursively allow such scalar folds. List/tuple operator results remain illegal; nested list operators may feed an outer scalar comparison. Map/binary/string operands to an operator, short-circuit forms and calls remain illegal. Literal strings and string-origin binary segments remain allowed; explicit integer binary segments remain illegal. Parser-only string origin survives existing segment expansion without changing established generated binary code.

Local construction rejects unknown declared fields before required-default checks; access/update/pattern captured-field behavior remains allowed because original lint classifies those missing fields as warnings. Imported/local definition collisions now use original reason/message ordering. Native construction/default/type diagnostics retain actual lexer UTF16 offsets, with metadata line/column counted by Unicode code points. These annotations cover this compile-time slice; they do not claim complete runtime source-stack propagation or canonical physical/native record pointers.
