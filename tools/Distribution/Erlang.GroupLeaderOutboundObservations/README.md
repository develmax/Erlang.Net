Prepared source only; neither this collector nor its new Erlang sources have been run or compiled. It complements the existing original DistributionSignalObservations input-controller cases with actual public outbound assignment between two original OTP nodes.

After source review and publication, the additive distribution-signal-observations workflow step uses that workflow's existing exact OTP29.1.1/ad05823719d77c8faee87348ea39513d4e2f99c5 source build and build-log evidence. No system-installed Erlang fallback, download or SDK/native ABI adapter is used by the collector. Direct invocation:

```text
python3 -B tools/Distribution/Erlang.GroupLeaderOutboundObservations/collect.py \
  --otp-source /absolute/clean-tracked-otp-source \
  --otp-root /absolute/source-built-install/lib/erlang \
  --build-evidence /absolute/beam-source-build-evidence.json \
  --approved-source-plan-sha256 <exact-reviewed-source-plan-sha256> \
```

The source-plan hash must match the exact UTF-8 LF file bytes. Every listed executable source/helper is hash-checked before importing local helpers. This reuses byte-exact process_capture.py and passive_etf.py from the existing raw-onload observation tooling; the specialized persistent-process owner handles only this collection's two nodes and foreground private epmd. The clean tracked original pin, six exact reference blobs, source-build receipt/log, installed OTP_VERSION, actual launchers/emulator hashes, both live node roots/versions and both compiled probe/driver image MD5 identities are checked. Networking is real and confined to loopback in this reviewed Linux x86_64 recipe. A freshly selected private epmd port, unique node names and an explicit non-secret test cookie isolate the two nodes; automatic epmd daemon launch is disabled. The client establishes the original connection before invoking the measured probe. Both nodes load the same compiled source directory. No actual SDK two-node transport is claimed: current production distribution exposes owned controller/input/output machinery, and its HOST checks observe emitted packets. The original side observes destination group_leader values after same-sender probes. These are separate backend roles, not normalized/equal native packet bytes or an end-to-end SDK live-peer comparison.

Four original contracts are checked from raw ETF: connected assignment is observed by the target; two updates followed by a probe observe the last leader; a dead local leader PID is accepted and observed; a known-dead remote target is accepted. Six ordered public-setter/probe outcomes, full raw PIDs, operation exceptions/class/reason/stack and cleanup outcomes are retained. The probe captures the primary outcome before cleanup, creates a fresh worker monitor, kills and joins the worker within 5 seconds even if readiness failed or an earlier DOWN was consumed, flushes the original monitor and preserves the primary fault over cleanup faults. The driver retains the worker cleanup independently and uses a bounded two-way server shutdown handshake. Normal execution requires the original worker to have terminated normally before the final dead-target setter and the fresh cleanup monitor to observe noproc.

Single git/compiler subprocesses use the existing owned process-group capture with explicit 10/30 second limits. The real two-node session has a 35 second deadline, node startup waits have 10 second bounds, server lifetime is 30 seconds and all Erlang receives have 5 second bounds. stdout/stderr go to complete files so background output cannot deadlock unread pipes; persistent streams exceeding 4 MiB fail collection and trigger cleanup. SIGINT/SIGTERM set cancellation: bounded single-process capture is allowed to settle, while node waits/startup poll cancellation. Finally closes all three owned process groups in reverse order, requests TERM then KILL as necessary, reaps every foreground parent and writes process receipts even on semantic failure. Automatic epmd daemonization is disabled. The receipt records process-group cleanup requests and parent reaping; it does not claim an OS-wide proof that arbitrary daemonized descendants exist nowhere. No external processes are selected for cleanup.
