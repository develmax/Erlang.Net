# Mixed local/external map observations

This standalone additive collector runs one genuine mixed_map_identity_probe in a fresh source-built pinned OTP VM. It reuses unchanged published NodeIdentity process, string and runtime-attestation helpers by compile links; it does not invoke the four prior probes.

Run with the source-built OTP root, a fresh output path, and source-build evidence JSON. It captures 32 declared raw files for before/start/stop reference and PID mixed maps: retained/rebuilt equality, ordering, map-key lookup, phash2 and current ETF bytes. Expected semantic outcomes are unset. Ports are deferred. Runtime, compile, disassembly and probe raw bytes/exit/deadlines accompany pin/JIT/build/source bindings. Completion means capture completeness only.

The joint manual packet workflow builds OTP once and launches packet and mixed-map observations in separate fresh VMs. No runtime identity implementation, network handshake or whole-module compatibility is claimed.
