# Original OTP reltool library

Pinned OTP-29.1.1 reltool 1.1: 9 original primary application images, sources, headers and available support files. Original bytes and upstream notices are preserved; provenance records source matches, relocations and excluded producer native binaries/debug symbols.

Reference Erlang.Otp.Reltool.Beam in an ordinary .NET project. OtpReltool.Modules lists the images; ReadImage, ReadApplication and ReadApplicationUpgrade return hash-checked independent copies. OtpReltool.Beam(module, dependencies) explicitly selects original BEAM execution on our .NET runtime. C# alternatives and native providers remain separate explicit choices. SupportFiles and ReadSupportFile provide whitelisted data; reading does not install assets or start applications.

No original VM executable or producer native library is shipped. Packaging does not certify GUI rendering, a native wx driver, debugger sessions, application startup, release generation, documentation examples or every API contract. The accompanying consumer compares finite original helper/class outcomes and complete error stacks with the pinned development oracle.
