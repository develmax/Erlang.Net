# Original OTP Megaco library

Pinned OTP-29.1.1 Megaco 4.9.2: all65 original BEAM images,95 original source/header/grammar inputs and two application resources. Every byte matches the admitted official release. Provenance distinguishes pinned Git sources, relocated inputs and generated release files; upstream notices and package license are preserved.

Reference Erlang.Otp.Megaco.Beam from an ordinary .NET project. OtpMegaco.Modules, ReadImage, ReadApplication and ReadApplicationUpgrade expose hash-checked original resources. OtpMegaco.Beam(module, dependencies) selects original execution explicitly on the .NET runtime. Dependency images and native providers remain explicit; there is no silent C# fallback or automatic application startup.

Finite timer/configuration and binary termination-ID observations do not certify every export, live H.248 gateways/controllers, TCP/UDP transport, ASN.1 native BER, flex scanner drivers or complete application boot. No original ERTS executable or producer native driver is shipped.
